## 🌱 Tentang saya

- 🔭 Saya membangun aplikasi Android dengan kode asli saya sendiri — dari alat keamanan, download manager, sampai server kata sandi mandiri.
- 🤖 Saya sedang belajar jadi **ahli AI** lewat praktik langsung, selangkah demi selangkah: AI agents, keamanan, dan bug bounty yang legal.
- 🌐 Visi saya: **dunia desentralisasi** — semua orang bisa jadi pemimpin lewat kontribusinya, dan keputusan dipegang oleh yang paling berkontribusi. Saya menuangkannya dalam buku gagasan *"Dunia Desentralis"*.
- 🐧 Pengguna Linux, tim MediaTek, dan ditemani 3 ekor kucing di rumah.

> *"Semua orang bisa jadi pemimpin lewat kontribusi satu sama lain."*

## 🚀 Proyek utama

| Proyek | Tentang |
| --- | --- |
| [Red-Eye-Mobile](https://github.com/tasirin1/Red-Eye-Mobile) | Aplikasi pemantau & pengaman HP via Telegram — menyamar sebagai kalkulator biasa, untuk jaga-jaga bila HP hilang atau dicuri. |
| [tasirin-download-manager](https://github.com/tasirin1/tasirin-download-manager) | Download manager Android dengan kendali jarak jauh lewat web, pengelola berkas, dan galeri video. |
| [tasirin-vaultwarden-host](https://github.com/tasirin1/tasirin-vaultwarden-host) | Server Vaultwarden (serasi Bitwarden) yang berjalan di Android — untuk STB/TV box dan HP lama. Cadangan ke Telegram, HTTPS, kunci PIN. |
| [netradar](https://github.com/tasirin1/netradar) | Pemindai jaringan lokal: port scan dan deteksi web tersembunyi di jaringan sendiri. |
| [alive-games](https://github.com/tasirin1/alive-games) | Kumpulan game AI vs manusia — AI bermain lewat API, manusia dari halaman web. Game pertama: catur. |
| [alive-bridge](https://github.com/tasirin1/alive-bridge) | Kotak surat FastAPI antara manusia dan AI — pesan dari halaman web, dibaca dan dibalas lewat API. |
| [world-of-decentral](https://github.com/tasirin1/world-of-decentral) | Gagasan tata dunia desentralisasi: kepemimpinan berbasis kontribusi (Proof of Contribution). |
